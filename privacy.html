Privacy Policy

Last updated: 15 November 2026

Mali Studio ("the tool") is a private production tool used by one independent creator to manage the creator's own six YouTube channels. Mali Studio uses YouTube API Services. Use of the tool is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Who uses the tool

Only the channel owner. The tool is not offered to anyone else, and it acts only on channels the owner has authorised through Google OAuth.

What data the tool accesses

  • The owner's own channel information (channel ID and title), uploads, playlists and caption tracks.
  • Public YouTube search results, used for topic research.

The tool does not access, collect or store personal data about other YouTube users or viewers.

How the data is used

Only to upload the owner's finished videos and set their thumbnail, subtitles, playlist, privacy status and scheduled publish time, and to check that each upload completed.

Storage and sharing

  • OAuth tokens are stored only on the owner's own computer, encrypted with the Windows user account (DPAPI).
  • No API data is sold, shared with or disclosed to any third party.
  • No cookies or tracking are used. This website collects no data.

Retention and deletion

Channel data read from the API is kept only as long as needed to finish and verify an upload, and is refreshed from the API rather than kept long-term. Deleting the tool's local token files removes all stored authorisation.

How to revoke access

Access can be revoked at any time at Google Account → Third-party apps & services. After revocation the tool can no longer act on that channel.
