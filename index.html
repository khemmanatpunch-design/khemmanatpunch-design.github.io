Mali Studio

A private production tool for six Thai-language YouTube channels owned by one independent creator.

What it does

Mali Studio is an internal tool that runs only on the creator's own computer. After a video is finished, it uploads that video to the creator's own YouTube channel as private, then sets its thumbnail, Thai subtitles, playlist and scheduled publish time. It also reads the creator's own upload lists and public search results for topic research.

The tool is not offered to the public. It has no users other than the channel owner, no ads and no fees.

YouTube API Services
